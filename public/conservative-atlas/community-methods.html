Hypergraph with Leiden or Infomap

We reconstruct the same complete supported groups used by the direct optimizer, then form a size-normalized projection: each group of size m and weight w contributes w / (m − 1) to each distinct member pair. This corresponds to selecting an incident group proportional to its weight, then selecting a different member uniformly. Infomap models this walk; Leiden optimizes mean-edge-scaled CPM on the resulting weighted graph. This is not a native higher-order CPM objective, direct hypergraph modularity, or an Infomap memory-network model. Different hypergraphs can produce the same projection, so whole-group distinctions can be lost. See the Map Equation researchers' hypergraph models and code and Leiden's graph and bipartite-model documentation.

The main canvas defaults to hyperedge envelopes in Hypergraph mode. Pair lines retain original citation or shared-reference counts; they are not the size-normalized optimization weights. Coupling thresholds choose eligible sources; whole reference groups may connect sources whose individual pair did not pass those thresholds. Bridge roles and connected-cluster filters continue to describe the original thresholded pair network. Use envelopes and exploded layers to inspect whole groups. Settings search and reliability use the selected projection, rebuilding hyperedge support and weights on each resample. Project findings retain the network model, hyperedges and algorithm. Ordinary cached Auto CPM is not a projection-specific recommendation: projection Leiden starts at its own mean-scaled density divided by four and can run a fresh CPM search via Find settings.

Leiden remains the default. Choose a method on the co-citation canvas. Scope, connection order and drill-down define the evidence; search, hidden clusters and line-display filters do not change membership. Changing method recalculates themes and layout. Cluster numbers and colors are not matched across methods.

Leiden CPM

The existing association-strength pair projection, ten starts and Auto CPM audit are unchanged. CPM and its slider apply only to this method.

Infomap

The official Infomap WebAssembly engine groups references by modeled random-walk flow on the same weighted pair projection. It minimizes the two-level map equation. Ten trials, seed 42, undirected flow, Markov time 1. Infomap does not use CPM. Higher-order input here is still a pair projection, not direct hypergraph inference.

Hypergraph modularity · exploratory

Each exact supported citation combination is one hyperedge. Single-order mode includes only that order; combined mode includes sizes 2 through the selected cap. Closed bundles losslessly supply candidate combinations within the selected reference universe; support is recomputed by intersecting actual source-reference incidence. Each combination must meet the selected joint-support minimum. Identical combinations are deduplicated.

Each supporting source contributes one total unit, divided equally among all included combinations it supports. This avoids multiplying its total weight through overlapping combinations, but does not make nested combinations independent. This weighting is a BiblioMap design choice and differs from Leiden/Infomap association strengths.

The objective is weighted linear-majority hypergraph modularity: a hyperedge earns the fraction in its largest community only when that fraction exceeds one half, minus its expected contribution under a weighted-degree-volume binomial null model. See the HyperNetX method documentation. The JavaScript optimizer independently implements this objective with seeded direct vertex moves. Three Leiden two-section starts, connected components, singletons and five seeded bundle starts provide ten initializations. The two-section is used only for initialization, not for the final objective. At most 20 passes per start; exports include convergence and every trial's score. This is a local-search heuristic, not a global optimum. At order 2 the objective reduces to weighted graph modularity.

The browser refuses more than 20,000 exact candidate combinations rather than silently truncating the analysis. Choose a narrower scope or lower single order if that bound is reached.

Reading the comparison

The audit reports adjusted Rand membership agreement with Leiden at its preserved CPM setting on shared linked references, plus coverage. One means identical membership up to labels; near zero means chance-level agreement under the adjusted-Rand model. Agreement alone does not establish stability or thematic relevance. Code length, CPM quality and hypergraph modularity are different objectives; their numerical scores cannot be ranked against one another.

Pair lines retain their original raw support or combined-score thickness. In hypergraph mode they are a visualization, not the optimization weights. Use the line inspector and exploded view to see exact combinations. Reference bridge roles describe the displayed pair-projection network. Use Roles & reliability in the shared canvas for method-specific checks: 10 preliminary or 50 fuller resamples, with two optimization starts each. Co-citation resamples source articles; coupling resamples reference IDs. Hypergraph checks rebuild support and evidence weights for whole groups; Infomap reruns the map equation. Fixed candidate universes, optimization variability and incomplete metadata limit interpretation. Recovery is not thematic validation. All three methods are available in both analysis tabs.

Export data includes method parameters, memberships, comparison coverage and all hyperedges with source IDs and normalized weights. Results are computed locally in browser workers; no API credentials are sent and no database records are changed.

# Publication-time windows and activity

Time windows rebuild full-count association-strength pairwise co-citation on the parent reference scope, or cosine source coupling using the parent sources' full retained reference lists. Each independent window uses the declared Leiden CPM, three starts and seed; unsupported algorithms, hyperedges, higher orders, filtered or alternative co-citation constructions fail explicitly. The same numeric CPM does not guarantee equivalent effective resolution across changing densities. This is not joint temporal Leiden.

Fixed co-citation nodes retain the parent reference selection. Changing nodes reapply its citation cutoff inside each window, still within that parent scope. Fixed coupling retains parent sources (out-of-period sources are unassigned context); changing coupling retains only parent sources published in that period. Unknown publication years, out-of-range sources and truncated boundary windows are explicit. Publication time is not the time metadata was observed: all windows use one pinned retrieval, not historical OpenAlex snapshots.

Every positive many-to-many community overlap retains member IDs and both denominators; any multiple overlap is a split/merge candidate, not proof of lineage. Numbers/colors are local. Entering/leaving and unassigned/common-node coverage remain separate. Completed-window selection redraws stored graphs with no computation. Selected windows are read-only analytical contexts: return to the full pinned map before new work. The series retains its bounded parent graph for restoring legacy findings; protected findings store the immutable series attachment and personal display window separately.

Activity uses Kleinberg's section 4 batched-document binomial model, not the interarrival-gap model: baseline probability is total feature-containing sources / total source exposure; elevated states multiply probability by a configured factor while remaining at most one. Upward state changes cost gamma × log(exposed periods) × level increase; downward moves cost zero. State-independent binomial coefficients cancel. The bounded implementation uses at most five elevated states, resets at zero-exposure gaps and requires at least five exposed bins and three supporting documents. [Original paper](https://www.cs.cornell.edu/info/people/kleinber/bhs.pdf).

Literal terms are title phrases, OpenAlex topics are classifier observations, and cited references remain limited to parent co-citation scope. Distinct sources contribute at most once per feature/bin. All-source exposure is the main denominator; observed-metadata availability is reported per period and compared with an eligible-metadata denominator as a sensitivity check—not an estimate of true completeness. Penalty, state multiplier, bin width and partial-year inclusion variants retain counts and intervals. The source vocabulary stays fixed across variants.

The retrieval year and later publication years are potentially partial or future-dated; activity excludes them by default. If the evidence date is unknown, the latest observed publication year is conservatively excluded. Temporal network windows instead include their explicitly requested dates and flag potentially partial latest periods separately from width-truncated boundary windows. No-exposure and entirely unavailable-feature-metadata periods have null rates and break model chains, never fabricated absence counts against known corpus exposure. Their all-source publication counts remain recorded; partially covered bins retain the declared denominator plus the metadata-availability sensitivity scenario. Unknown-year sources are counted, not imputed. A simple feature-share baseline and previous-three-bin share accompany the state model. Elevated states and baseline flags do not establish global attention, breakthroughs, relevance, causation, statistical significance or an optimum setting.

Bounds: 50,000 pinned sources, 3,000 analytical nodes, 20 windows over at most 100 years; parent graphs up to 100,000 edges and 500,000 retained incidences; three million candidate-pair contributions per window, 30,000 stored node observations and 300,000 stored edges per complete series. Coupling contributions are counted before pair materialization. Activity uses at most 200 explicitly selected observed features. Exceeding budgets fails without sampling. New immutable stage identities include evidence, settings, implementation and dependency checksums. Private artifacts retain project scope and normal authorization/cancellation rules.

Focused tests: `node --test scripts/temporal-series.test.mjs scripts/publication-bursts.test.mjs scripts/temporal-browser.test.mjs scripts/multiuser/temporal.test.mjs`. Disposable integration requires an exclusive, explicitly configured test database; never use research databases.

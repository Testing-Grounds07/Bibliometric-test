# Citation history

The third workspace tab adds direct source-to-source citation history inside the existing canvas shell. Search, Display, Inspect, Projects and export remain in the same tool panels. Existing co-citation/coupling analyses are preserved when switching tabs. This network is not forced into Leiden/Infomap communities: colors denote weak citation components and the interface makes no thematic reliability claim for them.

## Scientific contract

- Use the complete selected source corpus and available OpenAlex reference IDs. References outside the scoped source corpus do not become history nodes. Deduplication uses the corpus's existing identity cleanup; no new fuzzy merging is introduced.
- Construct one directed binary edge from citing to cited source. Ignore self-links, deduplicate repeated reference entries, and record both counts. Retain and flag citations to later recorded years; retain same-year citations. Missing years can be excluded or displayed in a separate undated lane, never assigned a fabricated year.
- Apply optional inclusive year bounds before computing the recursive k-core. Core degree counts distinct neighbors in either citation direction. Rank core articles by incoming citations from the complete core before the display cap. Keep separate incoming scoped-corpus counts. Deterministic ties use year then ID.
- Default k=0 and cap=100 are exploratory. The explicit Vogel-style preset is k=10, cap=100. An empty core stays empty. Display filters never modify the core, ranking or saved direct edges.
- Calculate transitive reduction on the top-N induced directed graph, not on paths through undisplayed sources. For a DAG, use topological order and bitset reachability; retain a direct edge unless another selected path reaches its target. For directed cycles, reduce the acyclic condensation graph, preserving every citation within strongly connected groups and all parallel direct links on retained group relations. This preserves reachability without arbitrary internal deletions but is not a unique edge-minimal reduction of the cyclic graph. The UI reports the protected cyclic articles. Subsequent component visibility filters may hide intermediate paths, explicitly disclosed in the UI.
- Keep the full selected edge set in `graph.links`, the reduction keys in `graph.historiography.reduction`, provenance, settings, coverage, date anomalies, cap counts and method text in the graph. Store snapshots and native Neo4j analysis edges as `direct_citation` / `DIRECT_CITATION`, not co-citation. Restoring a snapshot reinstates the history view and its parent co-citation baseline.
- Bounds: 20,000 corpus articles, 200,000 direct edges, 1,000 displayed articles. All violations fail explicitly; no silent truncation of the analytical corpus. The requested top-N display cap is explicit and audited.

`historiography.mjs` is pure computation. `historiography-worker.mjs` moves construction/core/reduction off the UI thread. `historiography-browser.mjs` mounts a chronological SVG in the existing `.network-stage`, reuses the mobile touch controller and shell panels, and extends the existing snapshot API without reconfiguring the other analyses. It supports camera pan/zoom, keyboard and touch, node/arrow inspection, component filtering, ranked evidence table, JSON and SVG export. No new search runs automatically and no history is saved without the existing Save finding action.
